## 当前能力

- **照片格式**：HEIF、JPG、TIFF；按镜头能力提供 RAW（DNG）、RAW＋JPG、RAW 转 HEIF（HEIF Pro）。RAW 捕获优先选当前路由公布的 Apple ProRAW 像素格式；若该路由没有 ProRAW 才回退 Bayer RAW，界面统一写“RAW”，具体类型取决于设备与镜头路由。HEIF Pro 输出 HEIF 容器，不是 DNG。格式弹窗把 HEIF Pro 放在 HEIF 下方，旁边以小号双行文字说明“通过 RAW 格式转换 HEIF，保留更多细节和降低锐化，并支持 Pro 影调”；顶部工具栏的 HEIF Pro 在横竖屏均显示“HEIF / Pro”两行。HEIF Pro 可选 10-bit PQ HDR，普通 HEIF 可选 HLG 实时预览与 PQ HDR 成片；边框输出为 SDR。12MP／48MP 按镜头开放，裁切会减少实际像素；A 挡选 48MP 时临时使用后置主摄 1× 并先预热，HEIF/JPG/TIFF/RAW/RAW+JPG/HEIF Pro 均按 48MP 输出，前置不开放。RAW 不应用滤镜，DNG 保留原始传感器画面。
- **Live Photo**：JPG／HEIF、12MP 时提供 Live 拍照，带拍摄前后环境音，可选麦克风授权；拒绝权限仍可拍无声 Live。开关 Live 会保留当前焦段取景，包括后置 1× 的 24mm/35mm。RAW、RAW＋JPG、TIFF、48MP 与 HEIF Pro 不发出不兼容的 Live 请求，入口显示为不可用。相册支持 Live 标识、长按播放和编辑。
- **视频**：底部直接切换照片/视频，使用 `AVCaptureVideoDataOutput` + `AVAssetWriter` 一次编码。真实支持 720p/1080p/4K 和 24/25/30/50/60/120 fps，按当前镜头及虚拟/物理路由能力开放；默认 HEVC SDR 1080p30，另有 H.264 与六种常规 ProRes。HEVC/H.264 可选默认、低、中、高码率；默认由编码器决定，其他档位按像素数、帧率和位深缩放目标平均码率，ProRes 由规格决定。SDR/P3、HLG HDR、Apple Log / Log 2 按编码和系统能力开放，音频 AAC 128 kbps 双声道。SDR/P3 视频支持照片滤镜和照片滤镜编辑参数，效果实时预览并在录制编码时烘焙；Log/Log 2 可从独立列表选择 57 款 Log LUT；“原片”后紧接“Log Rec709”和“Log2 Rec709”转换 LUT。可选择仅在预览中查看，或开启烧录后写入 10-bit Log 录像并保留 Log 文件标记。HDR 与 RAW 不应用照片滤镜。常规视频支持 4:3、1:1、16:9、2:1、2.39:1；分辨率以 16:9 基准定义，其他比例裁切后像素减少。RAW 两档需要授权合格外接盘及 RAW 物理镜头格式，按传感器与系统元数据保留画面，不任意裁切、套滤镜或自动转存相册。录制期间保留快门和 A 挡曝光控制，停止后恢复录制前模式；相册视频标识只显示时长、已应用的滤镜和 Log 状态，不显示摄像机图标。前置视频页另提供同步双拍：后置主画面、前置小窗，小窗支持拖动、双击交换和横竖画幅，位置写入成片并随保存设置恢复；正式入口固定 HEVC SDR 1080p30、16:9（竖向 1080×1920），HDR/Log/RAW 和其他规格尚未开放到双拍选择器。
- **滤镜与影调**：内置风格与 40 余款导入 LUT 滤镜，含由用户提供 CUBE 转换而来的美食 LUT 与黑白配方；分类、收藏、横滑预览切换。浓度默认 80%，0–80% 匀速、80–100% 加速，预览、照片、SDR/P3 视频成片与编辑共用同一条渲染配方。每款滤镜可保存色彩、明暗、效果三组参数（浓度、色温、色调、饱和度、褪色、曝光、亮度、对比度、高光、阴影、模糊／锐化、色差、柔光、光晕、颗粒大小、颗粒饱和度、暗角）。HEIF Pro 提供自然、胶片等影调与系统／全局／点测光。
- **拍摄控制**：自动／手动曝光、ISO、快门、白平衡、色调和对焦，按设备能力开放；A／M 切换时保存并恢复手动曝光、白平衡、对焦与 EV 记忆；支持目标曝光／对焦锁定、点按对焦、对焦辅助圈内 EV 调整。照片夜景仅支持A挡，开启夜景会自动切A、切M会退出；独立夜景需环境触发后才进入，按暗度与场景稳定性规划 3/6/9 帧，分批自动曝光包围并做曝光归一、运动区域保护、暗部降噪与影调提升；有效两帧保留双帧融合，无法融合时回退单帧，夜景标识按实际融合帧数记录。新增默认关闭的“流畅预览”辅助，仅照片 M 挡手动曝光有效，限制预览自动曝光的最长曝光时间；拍摄仍使用所选手动 ISO 和快门，视频不受影响。A 挡使用系统虚拟多摄自动选择物理镜头，M 挡使用物理镜头以保留自定义参数；系统切镜不添加过渡动画，并抑制相邻倍率反复切镜。
- **镜头与变焦**：预览支持双指捏合与张开调整倍率，并与变焦轮、固定焦段共用连续变焦状态及镜头路由；2×／4×／8× 固定入口按物理镜头或原生传感器裁切能力开放；每个固定焦段可长按拖出半圆变焦转盘，显示连续倍率，松手收起。支持动态画幅的前置相机使用同一个系统超广角设备，双箭头在约 31mm 普通取景与 20mm 广角取景之间切换，通过系统 sensor zoom 实现宽窄构图，不更换输入；既有前置方向自动宽窄切换保持不变。前置照片原“自动构图”按钮现用于切换竖幅／横幅构图：在 iOS 26 及以上、当前前置格式同时支持 3:4 与 4:3 时可用；RAW 和 1:1 下禁用。保持手机竖持也能预览并拍摄横向照片，4:3 JPG 真机输出为 4000×3000；前置宽窄按钮仍独立保留。连续变焦优先使用系统虚拟多摄像头，跨镜头时保持 M 挡参数并按新镜头能力钳制；数字放大不会标注为原生焦段。微距状态在 A 挡由超广角供图时显示图标。

### 2026-10-29 HEIF Pro HDR 层次与无锐化显影

- 用户同源 DNG/HEIC 对照确认：HEIC 两处灯光的高光压制有效，但中灰、黑位和暗部同时抬高，顶棚、墙面、百叶窗及桌面层次变平。DNG 线性中位约 0.144，本身已接近显影基准；旧 HDR 路线仍对最暗约 2% 区域追加约 0.70 EV，且“清新明亮”把黑点从 0 抬至 0.04，二者叠加造成泛白。
- PQ HDR 现以 RAW 默认显影的黑位和中灰为基准，不再套用 SDR 逆光恢复的全局/深暗增益，只对参考白以上保留连续高光肩部。“清新明亮”在 HDR 下改为保黑的轻量中间调提升，SDR 原参考配方不变。
- HEIF Pro 的 `CIRAWFilter` 同时将官方 `sharpnessAmount` 与 `detailAmount` 设为 0；此前只关闭前者，仍保留底片默认 0.5 的边缘细节增强。后续编辑中的用户主动“模糊／锐化”继续可用。
- 对用户提供的极影介绍视频抽取关键帧和字幕后，确认其公开描述也是 ProRAW 输入、关闭锐化、定制滤镜/四种影调、最高 48MP HEIF Pro、可选 HDR 与三种测光；视频无法证明其私有曲线或内部代码。光屿保留 DNG 同资产底片与可重新显影配方，是视频未展示的差异。
- 模拟器 5 项 HDR 黑位/中灰/高光/性能回归通过；iPhone 17 Pro 两项真机回归通过。四种影调正反顺序共 8 张均为 3000×4000、10-bit PQ，快速切换 40 次及恢复通过，未写系统相册。原办公室场景尚未用新版本重拍，最终主观层次仍待同场景验收。
