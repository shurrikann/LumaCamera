# 测光选项的实际行为

系统测光使用 AVFoundation 连续自动曝光，不叠加 App 的画面平均亮度补偿。切换测光模式时，测光关注位置恢复为中心。

全局测光在拍摄比例裁切后的预览上估计线性平均亮度，约每0.4秒微调系统曝光补偿，使平均亮度趋向18%参考值；有步幅和总量限制。这是 App 的平均亮度补偿算法，不是宣称调用了某个独立的苹果全局/矩阵测光模式。曝光锁定期间及自定义曝光模式下不再自动补偿。

点测光在点击预览时设置 exposurePointOfInterest，并使用系统连续自动曝光。实际作用范围和权重由系统决定，不能承诺严格固定面积的专业点测光。长按目标锁定曝光时，也会先在该目标位置测光再锁定。

ISO和快门同时处于手动自定义曝光时，以上测光不会自动改动它们。M挡内如果曝光参数仍为自动，则仍可以使用这些测光选项。选择测光模式会解除当前的目标曝光锁定。
