# 测光选项的实际行为

测光方式位于 HEIF Pro 的「Pro 影调」面板。其他照片格式及视频使用系统测光。旧的全局测光设置恢复为系统测光。切换测光方式会解除当前的目标曝光锁定。

- **系统测光**使用 AVFoundation 连续自动曝光，可叠加用户设定的 EV。
- **中央重点**以系统自动曝光和用户 EV 为基线。直径约为短边 55% 的区域权重最高，向外平滑降到 0.2。再比较中心加权亮度与全画面平均亮度：中心较暗时增加最多 +1 EV，较亮时减少最多 −1 EV，系数 0.5；中心与全画面接近时不干预。不再追固定 18% 灰，用户 EV 独立叠加。点按对焦时加权区域仍在画面中央。
- **点测光**在点击预览时设置 `exposurePointOfInterest`，由设备按它的测光范围计算曝光。长按目标锁定曝光时也会在该位置测光。
- **高光保护**以系统自动曝光的基础场景为基准，先从 32×32 亮度网格移除用户 EV 和已应用补偿，再剔除不超过 4 个像素的孤立高亮连通块。面积和峰值共用过滤后的亮区。亮区面积按 2% 进入、1.5% 退出滞回。面积 4%–8% 时，插值分位秩从 P99 平滑移向 P95，取样值限定在有效亮区。SDR 参考阈值为线性 0.90；HDR 使用预览实际 `contentHeadroom` 缩放阈值。留 0.15 EV 余量，基础补偿范围为 −2 至 0 EV。用户加正 EV 后高光可能更亮或溢出，这是用户选择。此前保存的「高光加权」选择会自动恢复为「高光保护」。

中央重点与高光保护每 0.2 秒最多分析一帧，在滤镜和影调前按当前画幅读出 32×32 线性亮度。场景稳定后才逐步下发曝光。M 挡的自动曝光可以继续应用补偿。取景界面保留主 EV 控件和直方图。

开启照片 HDR 后取景仍为 SDR，因此高光保护也使用 SDR 取景阈值。照片 HDR 与高动态显影继续处理 RAW 的亮部余量和暗部恢复。取景分位数无法用来保证 RAW 或成片的峰值。 [Apple 曝光兴趣点](https://developer.apple.com/documentation/avfoundation/avcapturedevice/exposurepointofinterest) [Apple 目标曝光补偿](https://developer.apple.com/documentation/avfoundation/avcapturedevice/setexposuretargetbias(_:completionhandler:))
