# 照片拍摄位置

CaptureLocationService 在相机前台可见时请求“使用 App 期间”授权并监听位置。权限拒绝、暂时不可用或位置超过 60 秒时，照片照常拍摄保存，不添加虚构位置。用户可在 iOS 系统设置中变更定位及精确位置权限。

PhotoLocation 是 Codable 值类型，包含纬度、经度、可用海拔、定位精度和定位时间。快门触发前复制快照，避免异步保存时误用后来的坐标。

系统拍摄 GPS 字典通过 AVCapturePhotoSettings.metadata 交给相机写入；应用重新编码的处理照片另外通过 CIImage properties 保留 GPS。RAW 数据保持系统提供的原始字节。PhotoKit 创建资源同时设置 location，照片拍摄诊断的结构化参数也保留位置。

详情使用原照片的位置显示地图并异步查询地点文字，无位置显示“未记录拍摄位置”，网络查询失败保留坐标。定位读取不参与缩略图和拍照渲染队列。旧照片不会被当前拍摄位置回填。

首次打开新版时由 iOS 展示授权提示；本次自动化测试没有代替用户作出定位授权决定。
