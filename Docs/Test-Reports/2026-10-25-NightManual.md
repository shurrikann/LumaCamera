# M挡夜景与手动曝光验证（2026-10-25）

## 本次能力

夜景可在A/M挡使用，进入时不再强制A挡。M挡保持自动曝光时使用现有自动包围；手动曝光时使用AVFoundation手动包围，所有批次重复快门瞬间的ISO和曝光时间，进行同曝光多帧降噪，不擅自改成±EV。现有环境触发、运动评估与3/6/9帧自适应策略继续生效，不保证每次均融合全部源帧。

M挡开启夜景后的应用调节范围为ISO100–3200、1/30–1秒，并与镜头硬件范围相交；屏幕刻度与实体相机按键菜单共用范围。白平衡、色调、对焦保留原规则。关闭夜景恢复普通参数调节范围。JPG/HEIF、12MP、无HDR/Live等现有兼容条件保留。

手动曝光测光用系统实际`exposureTargetOffset`修正ISO×快门估算，避免单纯调高ISO或延长快门就被误判成暗环境；这是应用策略，不是Apple公开的Night mode算法。无有效读数时不伪造环境判断。

## 官方依据

- [手动曝光包围设置](https://developer.apple.com/documentation/avfoundation/avcapturemanualexposurebracketedstillimagesettings)：原生按指定ISO与曝光时间采集。
- [包围照片序列](https://developer.apple.com/documentation/avfoundation/capturing-a-bracketed-photo-sequence)：按输出能力限制单批张数，本设备单批最多3张，应用分批追加。
- [曝光目标偏差](https://developer.apple.com/documentation/avfoundation/avcapturedevice/exposuretargetoffset)：提供相对目标曝光的EV偏差；不代表官方承诺本应用的夜景触发分类准确率。

## 设备、方法与结果

iPhone17Pro，iOS27.0.1（24A446），项目正常签名；只生成临时文件，不写系统相册，未启动模拟器。相关检查共43个不同测试方法有通过记录：策略/照片规格/读数28项、融合算法9项、硬件6项；不是重新全量测试。

- `Policy`：28项通过，3.879秒。
- `Device2`：M手动矩阵及M自动/A↔M两项通过，23.827秒。
- `NaturalRecovery`：自然暗光M挡、A挡3/6/9矩阵及9项融合算法共11项通过；取消测试最初误等成功回调失败，保留原记录。
- `CancelFinal`：修正取消完成条件为任务清空且无快门占用，并确认没有成功交付；M取消/返回再拍与A取消回归两项通过，9.829秒。没有为通过该测试修改生产取消语义。
- `RangesFinal`：新增加的实体按键范围断言误用`M.iso`标识，实际是`M.ISO`，导致该方法未进入采集；其他两项通过。修正为从枚举生成标识。
- `Verified`：最终两项通过，23.574秒；包括正确实体按键范围、全部源照片实际EXIF、27点夜景图标两状态真机渲染像素差异、三轮A/M往返。

源照片逐张读取EXIF，不能只用应用显示值验证。两轮各3组，共6次手动合成：

自然暗光测试未注入测光或运动：M自动实测ISO约2673、1/15秒自然触发；切M手动ISO400、1/4秒仍触发，实际采集并融合6帧，最终信息保留M与ISO400/1/4秒，该方法8.182秒通过。

稳定性覆盖夜景开关、A/M重复往返、拍摄退出取消、任务清空、返回再拍和A挡原流程。修复不可用的`moon.slash`符号，改用月亮与固定斜线，保持原27点背景和布局；最终真机渲染两状态尺寸一致且像素不同。
