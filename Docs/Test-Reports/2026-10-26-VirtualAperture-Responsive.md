# 2026-10-26 虚拟光圈星芒增强与连拖预览

用户反馈满档星芒偏弱且拖动卡顿。本次保留范围/默认值、控件位置与原格式限制。

## 修改

- 局部光源门限由0.76–1.0、局部对比0.08–0.32调整为0.62–0.96、0.025–0.16；均匀白色仍不触发。最大光线半径由短边7%改为12%，合成增益由1.15改为7。合成图实际外围能量约10.6倍，不能将其等同所有真实场景视觉强度倍数。
- 星芒辅助图上限768改为384，12次方向模糊+矩阵改为4次方向模糊，保留原分辨率成片底图。预览在效果前按现有900宽等比缩图，避免预览重复处理原采集分辨率。
- 光圈滑块接入现有交互预览代次机制，拖动中允许按单调代次发布已完成帧，松手重新收敛最新参数；消失时释放交互标志。滑动仅提交look，不重复提交对焦导航能力配置。

依据[苹果CIKernel说明](https://developer.apple.com/documentation/coreimage/cikernel/apply(extent:roicallback:arguments:))，滤镜图惰性求值，创建图的CPU耗时不代表实际渲染速度。本次改用主线程真实预览发布时刻检查；不是屏幕实际刷新率。

## 真机结果

iPhone17 Pro / iOS27.0.1正常签名，最终两项测试通过（硬件15.298秒、内核0.113秒整项含等待）。

- 三轮各90次、约16ms间隔参数更新，每轮发布46张实际预览；墙钟1.548/1.521/1.538秒，最大间隔49.1/50.1/47.6ms。覆盖松手后新帧与重新调节，共270次。指标是应用发布预览帧，不保证屏幕FPS，也不是实手触控延迟。
- 28组画幅/方向布局、镜头与格式限制、关闭/慢门互斥/切视频恢复通过。
- 主摄虚拟ƒ/8实际FNumber1.78，临时成片1.075秒；长焦虚拟ƒ/16实际FNumber2.799，0.610秒，各一张。详情独立软件值通过，不写系统相册。
- 合成点光源外围能量ƒ/1.4、4、8、16为0、109.524、380.861、837.962（旧版满档79.080）；均匀白图不增亮，4000×3000的4×4小光源通过。合成图渲染及读回样本约2.0/6.8/3.0/2.9ms；大图缩图检查51.3ms，仅各一次，不代表真实照片编码或FPS。导出满档附件已目视确认光线增强。

结果包`/private/tmp/LumaCamera-VirtualAperture-Responsive2.xcresult`，日志同前缀`.log`。
