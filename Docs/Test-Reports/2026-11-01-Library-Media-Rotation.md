# 2026-11-01 相册照片与视频显示方向

按用户本轮确认：竖拿时完整显示正向横图，横拿时旋转并适配更大的详情画布。相册按钮、列表照片及视频封面共用该规则；照片和视频详情的媒体随设备方向显示，页面及顶部/底部控件固定竖屏，视频播放条和标识继续随视频旋转。编辑流程保持原规则。

## 实现与官方依据

- App 将已有 CaptureControlOrientation 的角度独立传入 libraryMediaAngle；相册仍把 captureControlAngle 置零，仅锁定控件，媒体角度继续传递。视频详情沿用已有 videoPlaybackAngle，来源为同一个方向对象。
- LibraryMediaCanvas 在 90° 时交换内部宽高、居中旋转，旋转动画限定在画布。LibraryMediaThumbnail 使用完整适配；圆形相册按钮按矩形对角线适配直径，避免照片角落被圆形裁掉。列表只旋转媒体，格子与标识位置不变；旋转不重新请求缩略图。
- 照片详情的缩放视图、Live 媒体和格式标识一起旋转；切换方向结束 Live 长按并恢复适配，重新进详情不保留旧放大状态。新旧翻页画布各自旋转，翻页位移仍在屏幕水平方向。
- 照片四种本地方向手势始终只允许对应屏幕左右的两种参与；放大后全部退出翻页竞争。视频把本地拖动向量换算到屏幕轴，再判断翻页方向，视频翻页的旧帧也按媒体角度适配。
- 苹果明确说明 [rotationEffect 不改变布局 frame](https://developer.apple.com/documentation/swiftui/view/rotationeffect(_:anchor:))，因此需显式交换画布宽高；[UIImage 会按方向元数据显示](https://developer.apple.com/documentation/uikit/uiimage/orientation)，本次只加设备显示变换，不转写照片、视频或 EXIF。

## 真机结果

设备 iPhone 17 Pro（iPhone18,1），iOS 27.2（24B119），Xcode 27.1。证据根目录 `/tmp/LumaCamera-PhotoRotation-20261101`；配置 `MediaRotation-Final.xctestrun` 与 `MediaRotation-Paging.xctestrun` 位于 `/tmp/LumaCamera-NightCancel-DD/Build/Products`，可重复运行。

- 联合批次 Media-Final：30 方法中29通过、1失败，52.932秒。失败仅为旧测试写死两种本地方向手势；改为检查四种本地方向、恰有两种可翻页后，Media-Paging 定向1方法通过，0.002秒。最终30个不同方法均有通过结果，未再次全量串行重跑这30项。
- 照片：2宽度（320/402点）×7照片画幅×横竖两种图片×4方向＝112组。核对真实 PhotoZoomScrollView 宽高、完整适配、原 UIImage 引用、倍率；同一视图放大后旋转、40次快速变向、关闭重开通过，底部按钮截图差异断言通过。方向为真机渲染中的受控角度注入。
- 照片/视频缩略图：两类各9次方向设置，共18次；只请求2次、取消2次，每个资源各一次，旋转不清空/重载。完整矩形及圆形适配截图已目视，四角标记保留。
- 视频详情：临时 H.264 横片，2宽度×5次方向设置＝10组；AVPlayerLayer 为 resizeAspect、videoRect 保持16:9且包含于画布，顶部返回/标题/底部动作框不变，播放条与标识在媒体范围内。40次快速变向及退出通过；另一个视频信息/水平仪适配方法通过。
- 关联8项相册缩略图、9项混合分页、3项加载、2项照片分页动画、Live 手势和编辑缩放回归通过。8种 EXIF 方向的生成 JPEG 资源保持原方向值及数据；这是资源显示检查，不是新增相机出片或用户照片保存验证。诊断未写系统照片。
- 最终 Release 构建通过，源码警告0；保留工具自身的 AppIntents 元数据提取跳过提示。手机已退出测试并重新启动普通 App。

## 性能与限制

本次可重复指标为同一真机测试窗口的 UIKit 截图绘制成本：照片4样本，中位40.012ms、最大44.610ms；缩略图18样本，中位41.159ms、最大51.283ms。已有视频布局测试10截图（含附件创建）均值122.732ms、最大206.757ms。它们不是显示帧率、手势延迟、解码吞吐或应用内存指标。视频 AVPlayerLayer 的 UIKit 层级截图不能验证视频合成像素；本轮核对实际 player layer 的画幅和布局。

本轮使用生成图片和临时影片，未新增手持真实方向传感器验收、长时间播放/热稳或全项目回归。系统“减弱动态效果”继续读取环境开关取消画布空间旋转动画，本轮未实际切换系统该开关。历史 SLOW-RESUME-001 与 SLOW-META-001 状态不受此次修改影响。

## 保留的早期结果

照片首轮19方法中18通过、1失败（16条尺寸断言），原因是固定260ms后仍采到部分旋转动画的中间尺寸；测试改为等待目标尺寸稳定，随后照片阶段20方法全部通过（41.258秒）。后续用户追加视频范围后移除了临时照片/视频分支，统一封面显示规则；最终依据上述联合29项及定向1项。Build2 因测试尝试写只读的 accessibilityReduceMotion 环境值未编译，已移除该注入，未改系统设置。原日志和结果包保留。
