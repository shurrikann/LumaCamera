# 2026-10-26 虚拟光圈星芒

## 实现范围

拍照子模块中的虚拟光圈由占位接入功能；范围 ƒ/1.4–ƒ/16，初始 ƒ/5.6，连续对数刻度、不吸附档位。滑块位于慢门预设位置，宽高及中心对齐固定焦段背景条，按钮位置不变。基于 Core Image 与自定义 Metal 颜色内核生成八向星芒；这是艺术化软件效果，不改变硬件光圈、真实曝光或景深。数值越大星芒越强，ƒ/1.4接近原图。

仅后置主摄/长焦可选；入口在不兼容镜头时切到主摄，RAW/RAW+JPEG转为HEIF（不可用时JPEG），关闭Live。开启期间禁止前置、超广角、RAW及Live，切其他拍照子模块或视频则退出。系统自动微距仍由原虚拟多摄决定，超广角实际供图时暂停星芒，不强制切镜。设置保存机制记录开关和值。

预览和成片复用同一效果图；星芒辅助层长边最多768像素，缩图前保留微小光源峰值，原片底图不降分辨率。EXIF真实FNumber保留，软件参数写入独立UserComment标记，应用详情显示“虚拟光圈”。系统照片是否展示此自定义字段不作保证；纯原片资源不带该效果。

## 官方依据与实现区分

[Core Image motionBlur](https://developer.apple.com/documentation/coreimage/cifilter-swift.class/motionblur())、[CIColorKernel](https://developer.apple.com/documentation/coreimage/cicolorkernel)为所用系统处理API。高亮局部峰值选择、四条双向渐隐光线及强度曲线是项目算法，非苹果光学光圈模拟保证。

## 实际验证

iPhone 17 Pro / iOS27.0.1，正常项目签名。最终3项相关方法通过：对焦导航阈值/拍照/视频退出10.247秒，虚拟光圈镜头及成片11.167秒，内核合成0.188秒；这些整项墙钟含等待，不是帧率。

- 连续100次模型调节，7种照片画幅×4方向共28组布局，宽高与焦段背景条一致，无A/M与辅助按钮交叠；关闭、慢门互斥及切视频恢复通过。布局附件已目视检查，最后一组180°内容按既有规则旋转。
- 最终批次实际临时照片各一张：主摄虚拟ƒ/8，文件真实ƒ/1.78，完成0.923秒；长焦虚拟ƒ/16，文件真实ƒ/2.799，完成0.657秒。真实ImageIO读取、软件参数与详情行匹配。此前批次同样两张通过，约1.177/0.763秒。未写系统相册。
- 256像素合成点光源在ƒ/1.4、4、8、16的外围红通道能量分别0、6.181、29.038、79.080；均匀白色区域保持不变。4000×3000图中4×4微光源缩图后仍有星芒，外围能量0.211。最终单次渲染墙钟约72.2ms（包含合成图和读回），不代表12MP实际保存耗时或实时FPS。合成星芒附件已目视检查。
- 100次参数更新仅CPU模型提交，中位约0.025ms、最大约0.034ms；不包含GPU完成及屏幕呈现，不当作真实触控延迟。

结果包：`/private/tmp/LumaCamera-VirtualAperture-FinalChecks.xcresult`；日志同名前缀`.log`；机器指标见同目录JSON。

## 保留失败与限制

中间编译发现详情资源行误插入不存在作用域的properties，已修正，后续构建/测试通过。测试启动两次被手机锁屏阻断，解锁后最终通过；不计功能失败。真实夜景灯光观感、48MP/HDR/TIFF每种组合、长时功耗发热及其他设备未逐项验收；未进行全量回归。滑块模型100次提交不等同真实手指连拖性能测量。
