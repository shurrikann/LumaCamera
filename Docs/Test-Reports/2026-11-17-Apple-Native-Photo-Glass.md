# 苹果原生液态玻璃水印 — 2026-11-17

## 实现

当前iOS26+应用前台水印使用UIKit原生UIGlassEffect(.clear)，非手绘模糊叠层模拟。原生效果在照片中保存为静态材质，不包含交互动画。保留原卡片尺寸、横竖缩放和多行文字规则；系统自身的光学高光边缘会保留，不另外绘制白色stroke。

用非key、不可交互、屏幕外的临时窗口绘制照片与材质。取卡片周围24pt局部缓冲视口，正常UI尺寸短边360pt，在设备scale生成快照；只把圆角材质区域合成回原照片。其余原图不经过快照，文字最后按原照片像素渲染。窗口始终不盖住相机界面，defer隐藏并清空rootController。

## 官方依据与观测边界

苹果提供[UIGlassEffect](https://developer.apple.com/documentation/uikit/uiglasseffect)用于界面材质，[WWDC UIKit示例](https://developer.apple.com/videos/play/wwdc2025/284/)展示UIVisualEffectView的接入。[drawHierarchy](https://developer.apple.com/documentation/uikit/uiview/drawhierarchy(in:afterscreenupdates:))描述层级快照及完整性返回值。苹果没有把上述材质定义为独立照片导出接口；离屏材质能被正确保存是本机实测结果，不写成跨系统保证。

iOS26以下、没有前台scene、快照不完整时仍使用兼容渲染。系统材质可能随系统外观、透明度辅助设置改变；本轮未逐项人工验证所有辅助设置。后台保存采用兼容路径，未宣称与原生前台材质完全一致。

## 真机证据

设备iPhone17Pro（iPhone18,1），iOS27.2.1，Xcode27.2，诊断Photos写入0次。

2. 初版整图UI快照实验中，原图区域平均差异0.081/0.103超过阈值，故未保留整图替换方案；改成局部patch合成后横竖照片玻璃外抽样差异0，材质内差异0.442/0.450（测试图片与CoreImage差值度量，非亮度/FPS指标），主窗口保持，结束的离屏窗口均隐藏。
3. `/tmp/LumaAppleGlassRegression.xcresult`：13/13通过，24.916秒。含128组四样式/八画幅/四信息组合、八份JPG/HEIF属性回读、叠框地点OCR、横竖卡片、原生材质、连续工作线程导出和实际Live拍摄。
4. 20次800×600工作线程连续导出：15.39—22.46ms，调用结束主窗口未变、离屏窗口均隐藏。12MP固定图原生玻璃渲染n=5：34.080/24.746/23.542/25.820/24.730ms。仅处理耗时，不等于实际帧率、用户点击响应或拍摄总时间；没有App内存指标。
5. `/tmp/LumaNativeGlassActualFiles.xcresult`：真实专项1/1通过，21.793秒。显式开启玻璃水印，JPG/HEIF各拍一次Live，回读文件曝光、焦距、方向1、照片MakerApple配对ID与视频ContentIdentifier一致；视频分别完整解码89/90帧。静态预览已目视检查原生玻璃覆盖和场景内容，未写系统相册。
6. 纯灰背景样本已目视检查只呈现灰底与原生材质，无其他场景图像；此项为视觉观测，没有把非空快照返回值等同于材质正确。

## 限制

原生UIKit绘制需要主线程，已把窗口视口限制为卡片条带；仍有一次同步UI处理，不能把后台导出耗时当作UI帧率。未来系统升级需继续复测离屏材质；失败保留可出片的兼容路径。

未重新完成48MP、HDR、所有可访问性外观、真实后台保存下的原生材质或全部视频规格回归。普通视频/星空延时的视频样式不在本轮声明验证通过。选择/取消、模式切换和后台清理的原相机UI逻辑未改；本轮回退检查覆盖key窗口恢复、临时窗口隐藏和兼容路径守卫。

Release构建通过，已恢复普通App。
