# 2026-11-17 相册照片编辑水印

## 实现

照片编辑底部新增水印入口，复用拍照页的四种灰白示意缩略图、主题橙色选择态和实际水印渲染器：白色边框、液态玻璃、照片叠框、新年水印。点击启用，再点同一样式取消；位置、参数开关只修改本次编辑草稿，不更改相机偏好，也不自动启用水印。面板沿用局部淡入淡出与减弱动态效果，照片编辑内容和控件固定竖屏。

信息来自原照片元数据、PHAsset 日期/位置及本应用拍摄记录；不使用编辑时的手机定位替换拍摄地点。参数缺失沿用水印已有缺省显示，不编造 ISO/快门/白平衡。新选滤镜显示当前滤镜名称；原片选项保留原始烘焙滤镜记录。

水印在滤镜、几何和裁剪之后生成。裁剪时暂不显示水印，完成/取消后恢复，边框不参与裁剪。覆盖编辑用版本7的 PHAdjustmentData 保存可选水印配方，版本1—6仍可读取，重新进入时从原始编辑输入重建，不重复叠加。RAW+HEIF 重新显影在 HEIF 配方内保留水印设置，DNG 不改写。常规静态另存副本仍沿用原有扁平 JPEG 流程，不声称扁平副本可单独移除旧水印。

拍摄时已写入普通 JPG/HEIF 像素的旧水印，若没有无水印底图，不能无损修改其中的文字或玻璃遮挡区域；本次没有增加自动去水印或恢复不存在的原图功能。

## 官方依据

- [canHandleAdjustmentData](https://developer.apple.com/documentation/photos/phcontenteditinginputrequestoptions/canhandleadjustmentdata)：应用识别配方时，Photos 提供原始输入用于重建编辑。
- [PHAdjustmentData](https://developer.apple.com/documentation/photos/phadjustmentdata)：记录重建编辑所需的数据与格式版本。
- [PHLivePhotoEditingContext.frameProcessor](https://developer.apple.com/documentation/photos/phlivephotoeditingcontext/frameprocessor)：处理静态和视频帧；尺寸依赖参数需考虑帧的缩放。本项目按各帧实际尺寸计算同一水印布局。

上面为官方 API 语义。下述性能、配对、位深和布局为本次真机观测，不扩展为所有设备的保证。

## 真机结果

设备 iPhone17Pro（iPhone18,1），iOS27.2.1；Xcode27.2。

- `/tmp/LumaEditorWatermarkFinal2.xcresult`：23/23 通过，39.577秒；包含新功能与原有照片编辑、滤镜、缩放、元数据和 Live 回归。
- `/tmp/LumaEditorWatermarkDNG.xcresult`：1/1 通过，1.786秒。只读手机中已有 DNG，输出两份本地诊断 HEIF，不提交 Photos 修改。
- Release 构建通过：`/tmp/LumaEditorWatermarkRelease.log`。
- 所有诊断 Photos 写入0次；未执行真实覆盖/另存入系统相册。保存入口、配方快照、重复保存保护和失败重试使用替身回调；实际静态/Live 文件编码单独验证。

### 稳定性、布局与文件

- 320/390/440pt 三种宽度 × 八画幅，共24组真机承载。四项热区54pt、位于面板内；外部持机角度90°时编辑面板和按钮仍竖向。
- 576次样式启用/取消，另逐组选择新年水印；240轮面板快速打开/收起；每组裁剪后取消、保存面板取消、取消编辑后拒绝旧操作通过。
- 选中状态/位置参数随配方编码解码、覆盖重开草稿、关闭水印、保存中阻止修改，以及相机偏好不变通过。
- 横竖两尺寸 × 四样式 × 四种信息开关组合，共32份实际 JPEG。检查尺寸、方向1、EXIF 尺寸、ISO 和实际焦距保留；八份导出照片及三张最终界面截图已查看，布局无越界。
- Core Image 扩展范围像素检查：四种样式的照片主体保持超过 SDR 白点的值；玻璃仅在圆角卡片内覆盖，其他区域保留原高范围图像。
- 真实已有 Live：水印静态副本与动态片段、替换输出均编码成功，保留8项拍摄元数据、配对标识、still-image-time 和声音；时长1.7秒，照片3668×4011，视频1232×1346，副本/替换像素差异约0.00681。此项临时生成输出，不提交相册。
- 真实已有 DNG：以300万像素上限重新显影，新年/玻璃两份输出均为10位 HEIF、方向1，HEIF 内配方可读、样式正确，可清除配方中的水印；处理前后 DNG Data 相等。此项未覆盖所有镜头/分辨率的 RAW 实拍。
