# 照片/视频与星空模式取景交接（2026-11-16）

## 原因和变更

照片/视频和星空原先使用不同AVCaptureSession；停掉原会话、新会话配置/启动及界面替换都存在无画面的空档。第一版仅保留旧图、观察预览层已开始显示，用户仍确认双向闪黑；改为共用会话后退出正常，进入刚替换界面时仍闪黑，因此又增加跨页面的短暂取景覆盖。

- **同一会话/配置队列**：CameraEngine提供`AstroSharedCaptureSession`，星空三个引擎接受依赖注入。相机界面使用同一个AVCaptureSession和串行配置队列；保留各引擎已有RAW/融合/延时/恢复保存处理，不切回旧的简化星空算法。实验/独立测试入口仍可默认创建自己的会话。
- **独占图配置**：进入时保存主图的输入输出、preset、视频设备格式/帧时长、照片最大尺寸及视频连接方向/镜像。星空输入输出替换在同一个外层begin/commit事务完成；切回恢复主图，再由正常相机恢复参数。退出旧引擎仅释放所属UUID，延迟清理不能拆掉新图；不单独提交空图。音频输入随主图保存/恢复，不对音频设备设置activeFormat。
- **保持会话运行**：普通模式交接不调用stopRunning；主引擎停止自己的测光/预览处理时保留被星空占用的会话。背景、设置/相册休眠以及长曝光完成后的已有恢复路线仍按需停止；不会为了“共用”移除长曝光恢复保障。
- **取景覆盖与显示门槛**：旧图先经过两个显示时机提交，再更换模式。进入时另有位于两个界面之上的取景覆盖，保持到目标界面完成首次显示提交，随后由目标取景区的旧图接续；不对整页或按钮做淡入淡出。星空等待预览层已显示且新代理至少两帧，普通相机等待正确类型已配置后的至少三帧、跨度≥0.1秒。旧图0.18秒淡出，减弱动态效果0.1秒；5秒失败上限释放覆盖，真实错误仍显示。
- **预览位图**：`AstroPreviewFrameStore`最长边960px、最多4Hz生成位图，不持有捕获池buffer。星轨/延时复用现有输出，RAW照片增加预览尺寸BGRA代理。星空子模式共用同一个预览层，不再按mode ID反复拆装。
- **取消与生命周期**：模式显示提交、延迟镜头切换和启动任务均能取消；请求代次/图owner过滤旧操作。后台、设置和相册清除模式覆盖；星空隐藏后暂停其会话，回到普通模式的迟到暂停不会停止新路由。准备进度圈在快门内，其他按钮位置不变。

## 官方依据

[Apple会话配置](https://developer.apple.com/documentation/avfoundation/avcapturesession/beginconfiguration())说明输入输出等变更在最外层commit时原子提交，支持嵌套begin/commit；共用会话并不等于格式重配置不会短暂停帧。[AVCaptureSession](https://developer.apple.com/documentation/avfoundation/avcapturesession)说明startRunning是阻塞调用，应在串行队列运行。

[预览层isPreviewing](https://developer.apple.com/documentation/avfoundation/avcapturevideopreviewlayer/ispreviewing)及Xcode27.2 SDK同名头文件定义了开始渲染信号；这里还增加代理新帧与界面提交门槛，避免把“已启动”直接等同于完整视觉过渡。[预览尺寸输出](https://developer.apple.com/documentation/avfoundation/avcapturevideodataoutput/deliverspreviewsizedoutputbuffers)用于RAW取景代理。旧图保留、淡出时长和超时均为应用策略。

## 验证

设备：iPhone17Pro（iPhone18,1）、iOS27.2.1（24B156），UDID尾号0220401C；不拍摄到系统相册。

- 首轮真实可见界面测试1/1通过，32.219秒。进入8次1.001—1.437秒，返回8次1.507—1.827秒，均在实际预览信号后释放、无超时。指标为请求至淡出清理完成，20ms轮询，不是相机帧率或黑帧数量。
- 共享FrameRatio八个枚举值及三个星空子模式往返；每次检查旧图非空、返回图片取自当前子模式、最长边≤960及目标拍摄类型正确。Open Gate枚举仅检查布局/默认映射，不冒充硬件Open Gate能力测试。
- 三轮进入后60ms即返回，等650ms确认已离开的引擎未运行；取消交接后再次返回可恢复。
- 证据：`/tmp/LumaModeHandoff-20261116.xcresult`及同名log。
- 最终验收见下节。

## 指标范围

预览层状态与代理位图检查验证交接时序；未对屏幕逐帧录像统计黑帧。实际视觉观感单独记录用户反馈。自动测试的相机朝向/场景由设备当前位置决定；本轮不更改实际照片或视频文件。

## 共用会话阶段记录

- 共用会话原型八次进入1.343—2.112秒、八次返回1.673—2.167秒，85.561秒用例通过。它未证明视觉无闪黑，用户随后明确反馈退出正常、进入瞬间仍闪黑。
- 实际采集独立复验已通过（27.244秒）：同一会话两帧4032×3024 RAW、1帧星轨、3帧2160×3840延时（自动ISO/EV），最终返回普通照片正常。证据`/tmp/LumaSharedCaptureR3-20261116.xcresult`及同名log。
- 调试中修正了误对音频设备恢复activeFormat导致的异常；集成脚本曾因前一组隔离测试停掉主相机、未先重新启动而失败，已补就绪步骤。实际采集曾在子模式切换/恢复并行时挂起，移除按mode ID重建预览层后实际三种采集复验通过，未把未完成的挂起轮次计为通过。
- 跨页面覆盖单独仍未解决进入闪黑；真实录屏定位了初始整页变暗，最终取消整页初始淡入并限制弹窗动画范围后解决。

## 最终验收

- **用户观感**：最终普通App往返后，用户确认“进入和退出都正常”。
- **功能回归**：15项执行，13通过、2跳过、0失败，196.284秒；两个跳过项为需交互的录屏诊断及后台测试，分别另行执行。证据`/tmp/LumaSharedModeAcceptanceR2-20261116.xcresult`及同名log。
- **同一会话持续运行**：八种共享画幅枚举、三个星空子模式，8次进入1.317—1.649秒、8次返回1.423—1.639秒（请求到新画面门槛/淡出清理，20ms轮询）；KVO记录会话停止次数0，无5秒超时。三次快速退出含一次未完成的镜头切换，旧引擎均不再拥有相机图。
- **真实采集**：同一会话2帧4032×3024 RAW、1帧星轨、3帧2160×3840星空延时，自动ISO/EV路径通过；回普通模式再实际录像，37帧完整解码，然后返回照片。诊断视频回调独立接收并清理文件，不进入系统相册。
- **显示就绪**：子模式复用预览层后观察每次previewing状态；按模式、前后台和ready状态重启就绪等待，避免单次回调或过期ready把快门一直留在准备状态。物理测试等待真实previewReady再开始各子模式采集。
- **实际屏幕**：单元测试无系统截屏权限，改用用户允许的ReplayKit临时诊断。修复前后各捕获53帧；各取前31帧、中心ROI（x20%—80%、y25%—55%），编码RGB加权灰度相对各自前3帧中位数的最低值由14.37%变为100%。这是两条局部屏幕采样轨迹，不是实际显示FPS或所有场景的黑帧保证。修复前录屏在第8帧出现整页变暗，修复后未出现；随后用户手动确认正常。证据`/tmp/LumaHandoffScreenR2-20261116.xcresult`、`/tmp/LumaHandoffNoFadeScreen-20261116.xcresult`。真实取景诊断图只留在本机临时证据，不复制到仓库。
- **代理开销**：13组共32个代理帧，最长边960、最高4Hz，CI缩放/位图平均5.220ms，最大14.014ms；不等于屏幕帧率。代理不参与RAW成片融合。
- **原路径回归**：90次闲置刷新、93次采集中刷新、九次切镜及三个引擎预览恢复通过；13次启动/恢复参数稳定0.712—2.071秒。A/M原有过渡8轮无预览清空；1000轮胶囊状态、36组布局及挂载回调、视频准备取消/退出丢弃请求通过。
- **真实后台**：另1/1通过，39.544秒（含等待用户操作）；用户回主屏再打开，28帧星轨HEIC已保留且新协调器可读取，previewReady恢复、共享图归属正确、实际曝光回到1/15秒。证据`/tmp/LumaSharedBackground-20261116.xcresult`及同名log。
- **构建/恢复**：Release通过，日志`/tmp/LumaSharedModeReleaseFinal-20261116.log`。最终普通App启动成功。所有诊断不写系统相册。

图恢复还保留视频色彩空间、倍率、HDR策略、连接启用/方向/镜像及防抖请求。此次真实普通录像覆盖默认SDR路径，未穷举HLG/Log/ProRes、所有镜头和分辨率组合；未将这些组合写为端到端通过。星空真实星野与分钟/小时级热稳定仍需外拍验证。
