## 性能与稳定性样本

- 人像：180次调节、217次预览发布，发布间隔P95约47.09ms，最大56.77ms；55次分割中位9.98ms、P95 13.58ms、最大58.64ms。预览发布不是屏幕FPS。
- 近距微距：三次成片回调中位0.411秒、最大1.492秒；不等于从按键到屏幕完整呈现的时间。
- 慢门五预设冷恢复各完成恢复/退出/拍普通照，全流程9.797—9.980秒；10次短恢复0.502—0.800秒，20对快速启停通过。没有模拟成真正长期系统挂起，SLOW-RESUME-001仍开放。
- 慢门累积预览真实融合后发布：光轨20次、动态模糊5次、摇拍2次、流水14次；独立取消检查17次中间更新，取消后清理通过。不是输出影片帧率。
- 景深/光圈独立计时6次约3.006—3.028秒，持有、重置、取消重开通过。串行批次曾失败，未改代码，见问题清单。
- 弹窗显示链回调42个时间戳，平均间隔16.8ms、最大25.0ms；这是显示链回调节奏，不证明每帧内容都完成渲染。
- 连拍13张平均回调间隔0.333秒、在途峰值3，不是保证连拍帧率。Vision实际分类3样本中位49.62ms，3次取消未应用结果；候选受控，不能当成推荐质量评分。
- 视频滤镜640×360、30帧循环：Food Cube五次测量约7ms/循环；Log LUT十次冷暖样本约27.6—104.9ms/循环，冷启动方差较大。均非真实录像FPS。

没有采集独立正式App内存峰值或长期热稳；未以XCTest宿主内存冒充App内存。Core恢复测试主动注入运行错误，日志中的这部分错误是预期测试输入，不能直接当成新产品崩溃。

2. 智拍真实场景自动取景闭环未完成：20.7秒未得到可靠推荐点对齐，测试跳过；其他策略/真实Vision分类通过，不能据此宣称用户自然取景必然成功。
3. 系统端侧多模态模型返回deviceNotEligible，当前实际可用的是Vision分类回退；系统返回原因未细分，不归因为手机硬件本身不支持。

5. 长期慢门后台冻结、星轨尺寸EXIF不一致、用户仍感视频有些抖动沿用既有待办，未因本轮多数方法通过而关闭。电影景深观感未在本轮另做人物光圈AB验收。
