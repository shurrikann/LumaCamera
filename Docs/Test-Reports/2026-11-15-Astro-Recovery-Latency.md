# 星空长曝光返回取景延迟优化（2026-11-15）

## 最终方案

星轨和星空延时在采集结束、取消或失败后，如果设备读数仍为超过1/4秒的长曝光，停止并重建当前同一镜头的输入/输出路由。AVCaptureSession对象不变，沿用启动路径重新应用1/15秒取景参数。短曝光取景刷新不重建，星空RAW照片引擎保持原路径。

恢复前释放拍摄参数保护状态；路由重建保留完成、取消状态及已有错误，避免正常启动提示覆盖编码或保存结果。恢复不重新采集照片、不删除已完成合成数据，视频可继续完成编码。

依据：Apple stopRunning说明停止会话会停止输入到输出的数据流且同步等待完成；start/stop都在已有会话队列执行。曝光接口文档说明设置生效可能等待缓冲区时刻，不能把函数返回当作参数已经生效。

- https://developer.apple.com/documentation/avfoundation/avcapturesession/stoprunning()
- https://developer.apple.com/documentation/avfoundation/avcapturedevice/setexposuremodecustom(duration:iso:completionhandler:)

## 真机结果

设备为iPhone 17 Pro / iOS27.2.1。对比轮 FullR2 已通过7项测试。

| 路径 | 优化前秒数 | FullR2秒数 |
| --- | ---: | ---: |
| 星轨完成恢复 | 3.946 | 1.871 |
| 星轨取消恢复 | 4.062 | 1.998 |
| 延时完成恢复 | 4.055 | 1.769 |
| 延时取消恢复 | 4.050 | 2.008 |

指标为完成结果可见/发出取消后，实际设备曝光回到1/15秒且最大帧时长为1/15、会话运行的时间；20ms轮询，不表示屏幕帧率。优化前来自上一轮固定预览修复的Final真机记录，两组均为同一测试路径。

最终7/7通过，测试用例累计54.190秒。星轨/延时各完成一次，并各重复三次开始/取消；8个长曝光恢复样本为1.848、1.974、1.979、1.978、1.984、1.997、1.980、2.008秒，平均1.968秒。优化前4个对应样本平均4.028秒，平均减少约51.1%。全部低于3.5秒回归门槛，完成/取消状态保留断言通过。参数快速刷新、暂停恢复和九次切镜也通过。无系统相册写入：星轨关闭自动保存，延时用finishVerification封装临时文件，RAW不保存。

## 对照和范围

仅改变曝光/帧时长顺序、批量提交的对照依然接近4秒；只停启已有图的多种对照没有稳定保持1/15秒曝光，均已撤回。最终仅保留验证通过的路由重建路径。

本轮不改变星轨/延时的1秒采集曝光、不改变RAW星空照片采集、不修改自动ISO/EV或输出元数据算法。未进行长时温升、功耗、真实星空画质及显示帧率验收。用户已在普通App进入星轨、约6秒后取消，确认“恢复更快，画面正常”；未反馈明显黑屏或方向问题。该结论为用户实际体验反馈，未量化显示帧率。连续取消测试在设备已经进入1秒曝光后触发，未将“准备阶段立即取消”纳入本次速度指标。
