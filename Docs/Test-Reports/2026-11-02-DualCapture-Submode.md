# 2026-11-02 同步双拍子模块与主画面控件

## 范围

本轮把同步双拍从固定控制栏按钮迁移为视频子模块入口，并让双拍主画面决定焦段/变焦控件。

- 视频子模块恢复三列：延时、慢动作、电影、同步双拍、虚拟光圈
- 移除固定控制栏中前置人物居中右侧的同步双拍独立按钮
- 子模块入口图标：双拍 `rectangle.on.rectangle`，虚拟光圈 `camera.aperture`；开启时强调色
- 前置模式下子模块隐藏虚拟光圈入口
- 双拍开启时隐藏前置人物居中
- 双击小窗交换主画面后，控件跟随主画面切换

## 主画面控件

### 前置主画面

- 显示前置标准/超广角切换
- 保持前置取景逻辑，不显示后置焦段条

### 后置主画面

- 显示后置焦段条
- 1× 恢复 24mm/35mm 点按切换
- 长按焦段条打开变焦轮
- 变焦轮、捏合、焦段按钮都作用于双拍后置主画面的数字变焦，不重建会话
- 引擎在变焦后把 `selectedLens` 更新为距离当前倍率最近的固定焦段
- 命中的固定焦段按钮显示实际倍率，例如 2.6× 命中 2× 时显示 `2.6×`
- 未命中按钮保持固定焦段文字

## 实现位置

- `CameraEngine.dualCaptureMainIsFront` / `dualCaptureMainZoomRange`：发布双拍主画面状态
- `CameraEngine.setDualCaptureMainZoom`：双拍主画面数字变焦并更新 `selectedLens`
- `DualCaptureSource.setMainZoom`：锁定当前主画面设备并设置倍率
- `CameraViewModel.displayedFocalPosition` / `displayedFocalLenses` / `isFocalSelected`：按有效主画面过滤和后置焦段选中
- `CameraToolsPanel`：三列子模块、双拍入口、前置隐藏虚拟光圈
- `CameraCaptureControls`：移除独立双拍按钮、隐藏人物居中

## 限制

- 双拍后置主画面使用数字变焦，不切换物理长焦。
- 后置双拍不显示 0.5×，因为双拍主画面来自后置广角设备。
- 前置双拍不开放后置焦段条；长按前置超广角切换可打开变焦轮，但变焦作用于前置主画面。
