# 照片叠框地点、文字与模糊底框 — 2026-11-17

## 修改

叠框三边由原图宽6.5%收至短边3%，底部按实际完整信息列高度计算。字体、行距及Apple标志改按短边计算，横竖互换且短边相同时字体不变。地点/署名/参数可自动换行，避免长地点被单行省略。底图在最长边768px代理上的高斯模糊半径22→12，边框不裁切清晰原图。

原定位和已解析地址有内存缓存，但快门取位置仍检查60秒新鲜度和原50m精度门槛，室内或系统概略位置可能被过滤；这是代码可确认的缺口，不把它写成用户那次缺失地点的已取证根因。本轮为普通照片水印新增独立的watermarkSnapshot：60秒内、水平精度≤10km的有效位置可显示；>50m只显示城市或带“约”的两位小数坐标。GPS文件取值仍用原snapshot，未改精度、授权和recordLocation开关。地址、城市和最近位置继续内存缓存，前台停用后停止更新；未加持久化陈旧位置回退。

## 真机结果

- 四样式八画幅四信息组合共128次渲染、八份JPG/HEIF曝光/焦距/方向/尺寸回读通过。
