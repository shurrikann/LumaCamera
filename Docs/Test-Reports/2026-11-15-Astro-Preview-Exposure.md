# 星空取景固定曝光修复（2026-11-15）

## 实现

- 三个独立引擎启动完成配置后、startRunning 前应用预览参数，不再依赖界面早于会话启动的延迟刷新。切镜头重建会话也执行相同路径。
- 统一 applyAstroPreviewSettings：固定曝光1/15秒，支持15fps的格式同时设置最小/最大帧时长为1/15秒。仍应用用户的ISO、白平衡等取景设置。
- 完成、失败、取消后的在用会话恢复固定预览；引擎退出时沿用释放自动曝光/对焦/白平衡的清理路径。暂停后恢复会话也重新应用预览设置。
- AstroPreviewExposureGate 使用锁保护准备/采集状态。按下快门立即关闭预览配置通道，调用侧和会话队列执行时均检查；拍摄中排队或新发起的预览刷新不能覆盖采集参数。准备失败也会释放状态并恢复预览。
- 保留实际采集快门：RAW按用户选择；星轨/延时仍为1秒曝光、1fps采集。这次没有改成拍摄期间持续15fps取景，也没有修改自动ISO/EV测光算法。

## 验证

设备：iPhone 17 Pro，iOS27.2.1。R2真机4/4通过，包含3项参数测试及1项跨三个引擎的实际采集回归，耗时49.273秒。

- 每个引擎均先发一次早于start的刷新，实际启动后曝光和最大帧时长均达到1/15秒。
- 共90次快速取景参数刷新、93次拍摄准备/采集中刷新；真实RAW使用0.5秒，星轨/延时使用1秒，未被预览刷新改写。
- 三次真实采集完成和三次取消返回取景；RAW得到合成结果，星轨2秒叠加结果，延时至少2帧并封装诊断文件。
- 三组暂停/恢复、九次物理镜头切换（各引擎长焦→超广角→主摄），均重新进入固定曝光预览。
- 星轨禁用自动相册保存；延时使用finishVerification；RAW不调用save。无系统相册写入。

## 性能与限制

R2采用20ms轮询观察真实设备曝光/帧时长；9个延迟样本，分别为三个引擎的启动、完成恢复、取消恢复。启动0.899—1.185秒，完成恢复1.697—4.052秒，取消恢复2.068—4.060秒。该指标包含传感器参数生效等待，不能视为显示帧率或动画耗时。

从1秒采集返回预览时实测约4秒才达到稳定1/15读数，尚有恢复延迟。未做实际暗房/星空画质、显示帧率、长时间温升与功耗验收。
