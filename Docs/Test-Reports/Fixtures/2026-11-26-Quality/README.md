# 固定画质对照基线（2026-11-26）

设备：iPhone 17 Pro，iOS 27.2.1。主摄 1×、A 挡、12MP、4:3、系统测光、EV 0、原片、无水印。用户固定取景后，每组按七种规格正序、反序各拍一次；没有写入系统相册。

## 文件

每组保留七个第一轮 HEIC 原件、一张高动态拍摄产生的 DNG 底片、两轮指标与 SHA-256 清单。DNG 可作为同一输入重显影对照，HEIC 原件可核对 HDR 增益图；不要用缩略图或 SDR 联系表替代 HDR 观感验收。

`metrics.json` 的 P10/P50/P90 来自 SDR 解码后缩到 64×64 的线性 sRGB 亮度，不是画质评分。拍摄使用系统 AE，ISO/快门仍可能变化；跨次拍摄不能当作逐像素算法基准。

## 尚未覆盖

亮屏加暗部场景本轮无法配合，未采集；自然画质、肤色、HDR 屏幕观感仍需原文件人工验收。后续重显影应固定原始 DNG、配方、渲染环境与输出规格，并先检查清单哈希，不以重新取景的照片做像素全等断言。
