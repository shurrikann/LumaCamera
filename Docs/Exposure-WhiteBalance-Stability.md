# 手动曝光与自动白平衡

已移除按曝光偏移触发的自动白平衡保护，包括参考增益缓存、过曝时锁定白点、曝光恢复后解锁，以及逐帧读数触发的保护检查。

选择自动白平衡时，由系统持续测量和调整白平衡。手动 ISO、快门不会额外锁定或重写自动白平衡；手动色温和色调继续按用户设置应用。ISO 与快门仍按硬件支持范围写入，没有新增亮度限制。

高 ISO 下的颜色与亮度变化需要结合光源、实际白平衡增益和系统成像处理判断，不能仅凭偏黄认定为应用错误。

## 手动曝光预览与视频 HDR

固定电脑屏幕、实际 ISO 12096、快门约 1/125 秒的真机对照复现：视频 HDR 开启时高光压缩，文字仍清楚；关闭时高光明显更亮。64×64 sRGB 采样中亮度大于 250/255 的像素从 0/4096 变为 1918/4096，恢复 HDR 后为 0/4096。仅启用全局影调映射没有相同改善，因此不修改全局影调设置。场景存在轻微手持位移，数据用于诊断，不作为传感器标定或目标 App 完全等效证明。

自定义 ISO/快门生效前关闭自动视频 HDR 和视频 HDR；只在策略变化时重配置，拖动时不反复切换。按设备保存原始 HDR 状态，回到自动曝光时恢复；跨镜头重新配置后维持自定义曝光的 SDR 预览。自动白平衡继续由系统管理。该策略不改照片文件 HDR 开关或编码器，也不引入亮度补偿滤镜。成片处理仍需与预览分别核对。

诊断时临时使用的可变 HDR/全局影调 API 和测试已删除；保留只读 DEBUG 硬件状态查询，以及正常测试中针对手动 HDR 关闭、自动曝光恢复的断言。诊断图像只在 /private/tmp/LumaISOToneScreenResult.xcresult，不复制到项目。
