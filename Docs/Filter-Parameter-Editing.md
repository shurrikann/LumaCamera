# 滤镜参数编辑

2026-10-15：可选目录仅保留原片与徕卡 M9，全部/收藏列表同步限制；原有处理标识保留旧数据兼容，不出现在可选入口。M9 继续使用用户提供色表转换的 LUT。

## 使用方式

打开滤镜选择，点击滑杆图标进入参数编辑。顶部仅有色彩、明暗、效果三个选项卡，色调分离与 HSL 不显示。沿用现有蓝色玻璃弹窗；左侧返回列表，X 关闭参数窗口，省略号按钮打开应用内蓝色玻璃重置确认框，可重置当前滤镜。

| 分类 | 参数 | 范围 |
| --- | --- | --- |
| 色彩 | 浓度 | 0–100，默认 100 |
| 色彩 | 色温、色调、饱和度 | −100–100 |
| 色彩 | 褪色 | 0–100 |
| 明暗 | 曝光补偿 | −5–5 EV（图像处理，不改变相机曝光设置） |
| 明暗 | 亮度、对比度、高光、阴影 | −100–100 |
| 效果 | 模糊／锐化 | −100–100，负值模糊、正值锐化 |
| 效果 | 色差、柔光、光晕、颗粒大小、颗粒饱和度、暗角 | 0–100 |

浓度以外的参数默认均为 0。原片无基础 LUT，浓度显示“—”且不可调，拍摄元数据不记录误导性的原片浓度百分比；原片仍可以使用其他图像调整。颗粒大小为 0 时关闭颗粒，颗粒饱和度用于已经启用的颗粒。

## 保存和处理

FilterSettingsStore 按滤镜 ID 保存浓度和稀疏数字配方，默认数据与用户修改分开。切换滤镜、A/M、文件格式以及关闭窗口不重置配方，重新启动恢复最后选择的滤镜和对应修改。仅“重置当前滤镜”恢复当前条目默认值，其他滤镜的修改不变。连续滑动时合并持久化写入，拖动结束、关闭参数窗口和 App 失活时立即写出。

CaptureLook 持有不可变参数快照。预览和 PhotoEncoder 使用同一 FilterAdjustmentRenderer：先应用基础滤镜/既有影调，再进行色彩、明暗和空间效果。参数归一化并限制有限范围；空间半径按分辨率比例缩放，输出保持原图 extent 和 alpha。颗粒为固定坐标噪声，不因每帧随机变化产生闪烁。参数随 PhotoCaptureParameters 记录，供详情和后续边框内容复用。

单独 RAW 的有效配方清空，不应用滤镜或这些参数；用户原先配方仍保存。RAW+JPG 只处理 JPG 和预览，DNG 资源字节透传。

## 同轮界面调整

M 挡对焦弹窗下方人像/山峰从 13pt 放大到 19pt，近焦/远焦方向不变。拍摄模式移除电影静帧与多重曝光，增加“夜间模式”即将支持入口；本轮没有启用多帧夜景拍摄，30 秒慢门仍暂缓。

## 2026-10-15 连续调整与渲染优化

三个选项卡固定 334pt 内容高度，效果参数通过纵向滚动查看。去掉滑杆整数步进，图像处理接收连续值（UI 数字仍按参数精度显示）。拖动期间允许当前交互会话内已完成的预览帧按版本顺序发布，避免每次更新使在途帧全部作废；松手后严格恢复最终版本检查。图像结构改变设立新边界，停止会话会结束交互。会话队列合并积压的 look 更新，曝光、镜头代际等原有防护保留。

重置从系统 Menu 改为稳定的应用内玻璃确认层，淡入淡出。仅确认才恢复当前滤镜默认值，取消不改动；旧滑杆 Binding 的写入代际在重置后失效，避免迟到回调覆盖重置。切换滤镜、退出编辑和失活会结束拖动。

光晕、柔光仅将柔和的光效层缩至最长边最多 600px 计算，原图清晰底层保持完整输出尺寸；大幅模糊根据半径选择计算分辨率；色差合为一次 RGB 坐标采样。高档色差偏移增大，中心变化小、边缘明显。光晕增加近/远两层暖色亮部扩散。光效以保留底图 alpha 的加法核叠加，修正旧叠加使远端暗部变暗的问题。

颗粒从整幅等强度硬网格噪点改为平滑、零中心、随明暗密度变化的固定纹理；纯黑和纯白不叠灰，彩色分量受控。从 0 开始连续增加，不在启用瞬间跳到固定噪声强度。仍是数字模拟，不是物理胶片。

最终完整模拟器回归：177 项，174 通过、3 项真机用例跳过，0 失败。附加带演示预览的布局测试通过，核对 7 个画幅 × 3 选项卡、效果底部滚动以及玻璃重置层；截图共 22 张。GPU/软件渲染、最终预览与 TIFF、RAW 透传及旧功能回归均通过。

真机功能/图像测试 7 项通过；连续拖动约 1.06 秒发布 32 帧，测试拍摄配方正确、待处理数量回零，没有写入系统相册。逐项极值的短时帧率采样约为光晕 15.6、柔光 15.6、模糊 15.8、色差 20.4、颗粒 28.0、暗角 23.5 fps；受曝光、首次图形计算及场景影响，不能据此保证任何组合稳定满帧。
