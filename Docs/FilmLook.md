# 胶片感技术路线

智拍已移除，照片主线转为“胶片感”。目标不是加一层统一滤镜，而是让色彩、颗粒、高光和光学缺陷形成一个稳定、可重复的成像系统。

## 1. 产品原则

- 用户自己决定构图、曝光和按下快门的时机，不做 AI 提示或自动取景。
- 胶片感优先体现在直出照片和取景预览的一致性，而不是拍后再套滤镜。
- 默认克制、可关闭；每个效果都能单独调节，不强迫所有照片统一风格。
- 先做好 2–3 个可信的胶片 stock，再扩展数量，不追求“几十种滤镜”。

## 2. 技术分层

### 2.1 色彩科学

- 每个胶片 stock 使用一组固定参数：白平衡倾向、通道曲线、饱和度/对比、阴影色偏、高光色偏。
- 优先使用 3D LUT + 线性光空间处理；避免在 sRGB gamma 空间直接做通道混合。
- 建立标准测试：X-Rite ColorChecker、肤色、蓝天、绿植、暖光、霓虹。
- 同一 stock 在照片、Live、视频中尽量共用同一套色彩变换，但允许各自不同的动态范围处理。

### 2.2 高光与宽容度

- 胶片感的核心之一是高光滚降，而不是简单降低对比。
- 高光肩部（shoulder）单独控制，保留灯牌、窗光、皮肤高光的层次。
- 阴影趾部（toe）可抬黑或压黑；不要用全局曲线把中间调一起拉平。
- HDR 照片应先做色调映射，再进入 stock 曲线，避免高光被二次压扁。
- 为不同 stock 定义曝光宽容度，测光时可以轻微偏亮/偏暗，但不能假装增加传感器动态范围。

### 2.3 颗粒

- 使用亮度颗粒 + 少量色度颗粒，不要只叠一张静态噪声图。
- 颗粒大小随输出分辨率缩放；照片按最终像素，视频按预览/录制分辨率。
- 每一帧独立 seed，避免视频颗粒“冻结”；同一张照片多次导出保持稳定。
- 颗粒强度按亮度分层：高光和深阴影弱，中间调明显；避免暗部彩色噪点。
- 性能预算：Metal compute 一次完成，不在 CPU 逐像素循环；视频先保证 30/60fps 和热稳定。

### 2.4 Halation / Bloom

- 高光阈值以上做多尺度模糊，偏红/橙的光晕只叠加在高光边缘，不整体泛光。
- 控制强度、半径、阈值；人像肤色区域要限制，避免“塑料发光”。
- 与 HDR/高光滚降顺序固定：先 tone map，再 halation，再颗粒。
- 视频需逐帧稳定，不能因自动曝光变化导致光晕闪烁。

### 2.5 光学与画框

- 轻微暗角、边缘色散、镜头畸变可以作为 stock 的一部分，但必须可关闭。
- 边框/日期水印是可选装饰，不写入原始文件方向或破坏 EXIF。
- 不在取景器里伪造光学缺陷；预览和成片尽量一致。

### 2.6 拍摄控制

- 胶片 stock 选择、颗粒强度、halation、曝光补偿、画幅作为主要控制。
- 保留 A/M、曝光补偿、白平衡、焦点、测光；不引入自动构图。
- 预览应显示接近最终效果的色调，但避免为了观感牺牲对焦/测光可读性。

## 3. 推荐首批 Stock

建议先做三个方向，覆盖大多数场景：

1. **日光负片**：柔和肩部、偏暖肤色、低饱和绿，适合日常/人像。
2. **高对比彩色负片**：更强红/蓝、深阴影、明显颗粒，适合街拍/霓虹。
3. **低饱和纪实**：低对比、偏青阴影、细颗粒，适合阴天/室内。

每个 stock 都应有：预览 LUT、照片处理参数、视频处理参数、颗粒预设、halation 预设、支持格式/色彩空间说明。

## 4. 性能与稳定性

- 照片：在现有 `CaptureLook`/Imaging 管线内做 GPU 处理；不在主线程做全分辨率循环。
- 视频：逐帧处理必须进入现有录制输出，不二次编码；优先 1080p30，再评估 4K。
- 每次新增 stock 或效果都跑：照片直出、Live、视频录制、HDR、夜景、慢门、连拍、双拍。
- 记录 GPU 时间、预览帧率、热状态和电量；不以单次截图耗时代替实际帧率。

## 5. 实施顺序

### 阶段 A：基础色彩

- 统一 stock 数据结构与 LUT 加载。
- 落地 1 个日光负片 stock，照片 + 预览先通过。
- 色彩测试图和真实场景对比，确认肤色与高光。

### 阶段 B：胶片质感

- 颗粒引擎（照片/视频、分辨率自适应）。
- 高光肩部 + halation。
- 视频逐帧处理与性能门槛。

### 阶段 C：产品化

- 2–3 个 stock 预设、强度滑条、收藏/默认 stock。
- 边框/日期等可选装饰。
- 完整回归、功耗和长期热测试。

## 6. 验收标准

- 同一场景下，stock 切换只改变色彩/质感，不改变构图、对焦和曝光语义。
- 照片与预览色调接近，但不以牺牲可读性为代价。
- 颗粒在照片和视频中都不冻结、不闪烁、不产生彩色噪点。
- halation 只作用于高光边缘，肤色不过曝、不整体泛光。
- 所有效果可关闭；关闭后回到当前原始成像。
