# 相机操作边界验证

相机修改需要覆盖合理的快速操作和被中断操作，不能只验证一次成功顺序。基于改动选择相关项目：连续点击同一焦段、往返物理镜头和传感器裁切档位、变焦拖动中切换入口、M/A 连续往返、镜头切换尚未完成时再切模式、手动/自动参数混合选择、拍摄中重复点击、弹窗交叉切换、进入相册/设置及后台往返。

必须注入并检查暂时不可用的硬件读数：CMTime indefinite 对应的 NaN、无穷、零/负快门及 ISO、无效白平衡增益、过期镜头帧。未知值显示未知，不能把无效值转成整数，也不能用无效值覆盖用户手动设置。停止相机或切换输入后，丢弃旧输入的迟到回调。

模拟器验证格式转换、数据校验和状态切换；真实 AVFoundation 输入切换必须用真机验证。PhysicalCameraSwitchingTests 不拍照、不删除相册资源，执行 M 挡全部后置焦段往返、重复点击和回 A 挡，并要求预览及有效读数恢复。手机需解锁且测试签名可用。测试安装失败、测试跳过和构建成功，均不能记为真机操作通过。

布局验收继续遵循 Camera-UI-QA.md，覆盖 FrameRatio.allCases 的全部比例。压力测试记录覆盖范围和限度，不承诺任意操作都绝不会崩溃。


### 维护约束（用户要求，2026-10-14）

修复、优化或新增功能时缩小修改范围，保留其他正常功能。涉及共享相机管线时，回归 A/M 参数及自动选择保留、各焦段与前后镜头、滤镜强度/方向、对焦曝光、全部七种比例、照片保存与相册流程。测试通过说明已覆盖的范围，不承诺未实测设备行为。
