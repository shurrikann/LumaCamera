# 相机界面核对要求

任何涉及拍照界面布局的调整，都必须核对 `FrameRatio.allCases` 的全部可选比例，不只核对用户举例的 4:3 和 16:9。当前包括 4:3、1:1、3:2、16:9、2:1、2.39:1 和 XPAN；新增比例也纳入核对。

逐一检查预览边界、顶部工具栏、底部曝光栏、焦段按钮、弹窗和变焦盘的裁切与遮挡。对焦功能还需检查中央及四角目标，对焦框、AE 锁定提示、小太阳和 EV 数值应位于可见范围内，并避开工具栏与曝光栏。焦段布局应覆盖真实设备可能提供的不同按钮数量。

2026-10-19 起，照片和视频的电影画幅统一为 **2.39:1**，旧 2.35:1 文字仅保留在历史记录。水平仪检查覆盖照片七种比例、视频五种比例及四个控件方向；横屏需检查水平高亮、倾斜方向和触感防重复门限。帧率选项按当前路由能力禁用，显示值必须与实际应用值一致；分辨率/帧率切换沿用局部取景过渡，不能移动操作按钮。视频详情沿用照片信息卡片及玻璃面板，播放画面不缩小，耗时读取在详情按钮中显示加载圈。

截图验证布局，自动测试验证状态及边界条件；真实测光、曝光锁定、手势竞争、硬件镜头切换和震动需要真机验证。记录实际检查范围，不把模拟器演示当作硬件功能验证。

## 2026-10-17 控件旋转与文字边界

界面保持竖屏坐标，按设备姿态旋转内容。相机、相册和详情操作按钮不重新布局。编辑刻度仍在原底部区域，用户实际横拿后位于侧边且上下拖动，不再额外旋转刻度，避免盖住图片与裁剪手柄。A 挡曝光标题/数值作为一组旋转，保持双行。

## 2026-10-17 黑色背景与深色玻璃弹窗

相机页背景由深蓝改为黑色系渐变，覆盖取景背景渐变、顶部压暗渐变和取景占位底色。弹窗、玻璃面板、吸底滤镜面板及相册／详情／编辑底色由蓝灰改为黑灰；`AppTheme.popupColor`、`PopupGlassBackground` 渐变、`GlassSurface` 覆盖层与阴影只替换 RGB 通道。

弹窗材质升级为多层深色磨砂玻璃：深色染色与 `ultraThinMaterial` 磨砂、上部受光／下部加深、对角高光与椭圆光晕、静态细颗粒、亮边与底边内阴影、双层投影。颗粒来自共享静态纹理，不在滚动或弹窗动画中重新生成；系统开启“降低透明度”时回退为高不透明度黑灰填充。材质层不参与命中测试。

当前透明度与结构：`popupOpacity` 为 0.86（平面弹窗与预览表层），`cameraPopupMaterialOpacity` 为 0.66（磨砂玻璃弹窗），`PreviewSurface` 默认为 0.28，玻璃渐变仍为 0.18／0.32，`GlassSurface` 覆盖层为 0.52。按钮玻璃底比初版更明显；禁用按钮只把图标／文字降到 `disabledControlOpacity` 0.46，背景和点击热区保留。强调金、手动参数橙、演示画面与照片像素不变；强调色上的文字和图标统一使用 `AppTheme.accentForeground`。

核对要求：七种比例及左右横屏下不残留蓝色背景；顶部和底部弹窗、吸底滤镜面板、相册、详情与编辑使用同一深色玻璃主题，尺寸、弹窗位置与弹窗动画不受透明度调整影响；禁用按钮（格式选项、滤镜与翻转、工具项、照片页操作）仍能辨认背景，仅内容变淡；颗粒无明显重复接缝，边缘高光不越界。已核对拍照页、参数面板、滤镜面板、辅助工具、功能切换和顶部格式面板截图。

弹窗显示期间切换横竖屏时，先将旧布局卡片淡出、轻微缩小与倾斜，在不可见时切换到新布局，再淡入；底部弹窗在淡出期间保持旧边缘位置，随后才切换到新的屏幕边缘。系统开启“减弱动态效果”时只保留更短的淡入淡出。过渡仅作用于弹窗自身，不带动相机页面其他区域，按钮位置保持稳定。横屏卡片内部的图标继续按控件角度旋转。
