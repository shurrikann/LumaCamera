# Pro 影调参考校准

2026-10-16 用户提供两组 JPEG：`heif原片[1].jpeg` 及自然影调、电影质感、高对比度、清新明亮 `[1].jpeg`，来源 Downloads。输入先按 ICC 转换至 sRGB，再比较亮度分布、饱和度和可辨识物体。

这不是同一输入的四次处理：照片存在位置、构图、对焦及可能的自动曝光变化，第二组普通 HEIF 原片的视角尤其明显不同；JPEG 中没有可用拍摄参数，不能推导目标 App 精确 ISO、快门、白平衡或专有曲线。统计仅描述外观方向，不用于逐像素拟合或声称复刻目标算法。

## 两组共有的方向

- 电影：抬黑、压高光、减弱饱和度。第一组自然/电影 1% 明度约 0.034/0.078，99% 约 0.889/0.866；第二组约 0.020/0.066 与 0.941/0.898。
- 高对比度：阴影及中间调更深，保留亮部。第一组自然/高对比中位明度约 0.431/0.211，第二组约 0.518/0.410。构图与拍摄变化意味着这些并非精确曲线对应点。
- 清新明亮：抬升中暗部、反差减弱、色彩较柔和。第一组自然/明亮中位明度约 0.431/0.537，第二组约 0.518/0.720。
- 自然：保留光屿 RAW 解码后的中性基准；不把普通 HEIF 的系统锐化、曝光与多帧处理差异强行拟合为全局调色。

## 实现

`PhotoTone` 使用同一个预览/照片处理入口。电影、高对比和明亮改用 Metal 明度曲线，五个感知明度节点通过单调 Hermite 插值，保留色相关系并分别调节饱和度；自然不额外调色。超过 SDR 白点的亮度使用与末端斜率衔接的线性 HDR 延伸，不截断为 1，不压成普通 8 位后再标记 HDR。

| 影调 | 0 / 0.25 / 0.5 / 0.75 / 1 对应输出 | 饱和度 |
|---|---|---|
| 自然 | 0 / 0.25 / 0.5 / 0.75 / 1 | 1 |
| 电影 | 0.055 / 0.30 / 0.515 / 0.735 / 0.94 | 0.83 |
| 高对比 | 0 / 0.10 / 0.35 / 0.72 / 1 | 1.04 |
| 明亮 | 0.04 / 0.38 / 0.62 / 0.82 / 1 | 0.86 |

这些是本项目校准参数，不是目标 App 内部数值。HEIF Pro 开启 HDR 时，RAW 以扩展动态范围解码，先应用影调再编码 10 位 PQ HEIF；既有保留 RAW 画质的 SDR 取景策略不变，取景仍可看到影调的 SDR 外观。

`Reference-Comparisons/ProTone-References.jpg` 为用户两组参考图缩略排版。`ProTone-Same-Input.jpg` 用项目同一 Metal 内核将四种影调应用在每组普通 HEIF 原片的 JPEG 上，目的是核对同输入的相对变化；它不等同于真正 HEIF Pro RAW 开发或目标 App 输出。

## 纹理第二轮增强（2026-10-16）

- 颗粒饱和度 0 为单色，100 的色度噪声幅度扩大为上一轮的 4 倍，仍保留共同明度噪声、随亮度变化的密度及逐帧变化的纹理。没有通过提高整张照片饱和度模拟彩色颗粒。颗粒大小为 0 时不产生颗粒。
- 褪色改为线性的暖黄老化矩阵，并少量混合通道，100 时明显泛黄，0 保持原样；保持深黑位，不使用白色蒙层。R 系数为 (1−0.10f,0.18f,0.06f)，G 为 (0.08f,1−0.23f,0.03f)，B 为 (0.025f,0.025f,1−0.88f)，f 为 0…1；偏置仍为 (0.006f,0.004f,0.0005f)。
- 使用用户的同一张实际照片分别渲染 0/50/100 并核对全图及颗粒局部，参见 Reference-Comparisons/Fade-Grain-Second-Pass.jpg。处理入口仍共用于预览、拍照及编辑。
- Pro 影调四张卡片将“自然影调、电影质感、高对比度、清新明亮”独立放在图片下方，避免名称随图片布局被裁切。面板同时完整显示测光行。
