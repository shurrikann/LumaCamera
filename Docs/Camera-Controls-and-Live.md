# 相机固定布局与 Live（2026-10-15）

最低运行版本为 iOS 18。所有比例共享顶部工具栏、焦段、A/M、辅助入口、曝光/手动参数行及底部五按钮的屏幕坐标，只有画面窗口的范围改变。4:3、1:1 的画面从工具栏下开始，其他比例延伸至工具栏后方；直方图留在工具栏背景下方。预览按实际比例完整缩放进底部五按钮上方的可用空间，16:9 及更长比例不再伸到这排按钮下面；工具栏覆盖的像素仍属于预览画面。

辅助弹窗为两行图标，去掉底部说明，图标放大。峰值分析未加滤镜的传感器边缘，在显示图像上叠红色提示，不加入照片。每次重新打开滤镜先回列表并定位已选项，参数仍保留。

## Live

HEIF Pro 保留 Pro 影调入口。其他格式显示 Live 开关，两态切换；本次不提供 4K Live。

系统 Live 捕获支持当前镜头的 12MP JPG/HEIF。RAW、RAW+JPG、TIFF、48MP 不发出不兼容的 Live 请求，入口显示不可用状态并说明所需格式，保留用户原格式和参数。准备会话时一次性开启系统 Live 管线，点击开关不重建会话。首次开启 Live 请求麦克风权限；授权后按需添加麦克风输入，Live 带拍摄前后的环境音。拒绝权限时仍可拍无声 Live。关闭 Live、切换到不兼容格式或离开相机后移除麦克风；如果有在途捕获则等其结束再调整输入。

Live 的静态照片和动态视频都应用快门时的滤镜、参数和画面比例。静态照片重写时保留原始 Apple MakerNote 配对标识，视频导出保留 content identifier 和 still-image-time 元数据轨；使用 PhotoKit 的 photo + pairedVideo 一次性保存为一个实况照片。保存时统一暂存为真实文件，并指定 UTI，直到异步相册事务结束才删除临时文件，修复 3300 资源校验失败；普通照片沿用相同保存流程。视频导出保留音轨，并检查源视频有声音时输出不能丢失音轨。短视频文件异步处理，任务数量受拍摄权重上限限制，完成或失败均清理临时文件；资源跟随原有保存队列，失败可重试。

相册列表及详情右下角显示 LIVE，系统相册现有实况也通过 photoLive 子类型识别。详情照片切换动画同时携带 RAW/LIVE 标识，其他操作按钮不参与滑动。

## 删除与相机恢复

列表保持系统相册抓取顺序（拍摄时间由近到远）。删除后取原列表的下一项，不另按时间查找，也不向较新项回退；列表末尾先加载后续页，无后续时回列表。批量删除仅选择已加载照片，通过一次 PhotoKit changes 提交，只显示系统确认；取消/失败保留选择和照片。

恢复相机及 ready 事件后重新应用 UI 保存的曝光、白平衡、对焦与测光设置，不依赖镜头 ID 改变。恢复时携带 customExposure 状态，避免同镜头恢复后只有 UI 正确而设备返回自动。

图像内核迁移为构建时编译的 Metal stitchable 内核，移除 CIKernel(source:) 运行时编译及弃用通知名称；没有通过静音弃用警告掩盖问题。
